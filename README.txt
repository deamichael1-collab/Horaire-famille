# Planificateur familial hebdomadaire

Application web simple pour planifier la semaine.

## Nouveautés de cette version
- Sélection de la date du lundi.
- Les dates de mardi à dimanche se mettent à jour automatiquement.
- Option ajoutée : Jules dort chez Mamie.
- Cette option s'affiche en orange dans le calendrier et dans la légende.
- Export PNG du calendrier hebdomadaire.

## Utilisation
1. Ouvre `index.html` dans Chrome, Edge ou Safari.
2. Sélectionne la date du lundi.
3. Coche les journées :
   - Ariane absente le soir
   - Mamie va chercher Jules à la garderie
   - Papa est à Montréal
   - Jules dort chez Mamie
4. Ajoute les rappels, tâches ou jalons.
5. Clique sur `Exporter PNG` pour générer une image du calendrier hebdomadaire.

## Notes
- La sauvegarde se fait localement dans le navigateur.
- Aucune installation nécessaire.
